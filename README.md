# Writing Approach

Technical writing should preserve the substance of the subject while making that substance easier to understand, evaluate and use.

My approach emphasizes:

**Technical accuracy**  
Engineering concepts should remain technically coherent and defensible.

**Structural clarity**  
Complex subjects are organized so that readers can follow the underlying logic.

**Research-based analysis**  
Technical claims and conclusions should be grounded in appropriate technical evidence.

**Audience awareness**  
The depth and presentation of technical material should match the intended readership.

**Professional readability**  
Technical writing should be precise without becoming unnecessarily difficult to read.
